Desarrollo con agentes

Cómo arrancar y llevar una feature con un agente de IA (Claude Code u OpenCode) usando el setup del repo smartruck-ai.

Quick path

  1. Instalar el setup siguiendo la guía de instalación del README de smartruck-ai.
  2. Abrir el agente con el wrapper de la carpeta de repos: <carpeta>/bin/claude-smartruck o <carpeta>/bin/opencode-smartruck.
  3. Pasarle la historia del Board:
/nueva-feature roadmap#<N>

Fases

FaseQué hace el agente
1. PreparaciónActualiza todos los repos de la organización y docs. Lee la historia y asegura los criterios de aceptación. Actualiza los Gherkins en el .feature del repo (con @wip) y en el ticket. Pasa la historia a In progress.
2. GateMuestra el plan (escenarios, capas, archivos y decisiones abiertas) y espera la aprobación. Es la única pausa.
3. EjecuciónEscenario por escenario, en main: rojo, verde, commit y push, refactor, commit y push.
4. CierreCorre la suite completa, actualiza el README del repo y docs, libera a test con release_to_test y pasa la historia a In review con las horas insumidas.

La liberación a prod y el pase a Done no los hace el agente: los hace el equipo al final del sprint (Workflow de entrega).

Reglas del agente

  • Los criterios de aceptación son los escenarios Gherkin (Gherkin).
  • Ciclos de TDD de un test por vez, de afuera hacia adentro, con un commit y un push por ciclo (Conventional Commits).
  • Solo usa las skills del setup del proyecto, no las globales de cada persona.
  • Las horas insumidas las informa la persona; el agente no las estima.

Skills principales

SkillPara qué
nueva-featurePunto de entrada: preparación, gate, ejecución y cierre
criterios-aceptacionReglas y escenarios de una historia
bdd-tdd-executionCiclos BDD + TDD después del gate
release-ambientesRelease a test
board-sprintEstados y horas en el Board
